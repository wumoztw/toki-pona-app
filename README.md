# Toki Pona 互動學習網頁應用 (Toki Pona Learning App)

這是一個專為華語使用者打造的現代化 **Toki Pona（道本語 / 善語）** 互動學習應用程式。採用零建置、免編譯的單頁式現代網頁架構，結合豐富的字彙資料庫、漸進式造句練習、個人化學習進度追蹤與互動隨堂測驗。

---

## ✨ 核心特色

1. **道本語核心 120+ 詞彙資料庫 (`data.js`)**
   - 完整收錄 Toki Pona 官方與常用核心單字。
   - 包含詞性、中文釋義、例句與詳細說明，方便隨時查閱。

2. **漸進式造句與互動練習**
   - 引導式學習設計，幫助初學者輕鬆掌握道本語精簡而富有哲理的組詞邏輯（如複合詞、修飾語順序）。

3. **localStorage 單字掌握度紀錄**
   - 自動將使用者的單字熟悉度、測驗成績與學習歷程保存在瀏覽器本地（`localStorage`）。
   - 隨時開啟、隨時接續進度，隱私安全且無需註冊帳號。

4. **隨堂測驗模式 (Quiz Mode)**
   - 多樣化的互動測驗題型，檢驗單字與造句的學習成效，強化記憶曲線。

5. **零建置、高效單檔/模組化架構**
   - 無需複雜的 npm 建置工具鏈或打包程序，使用原生 HTML5、Tailwind CSS 與現代 JavaScript 打造，載入迅速、相容性高。

## 💡 本地快速預覽

只需將專案複製到本地，並使用任意靜態伺服器（如 Python http.server 或 VS Code Live Server）開啟：

```bash
# 使用 Python 快速啟動本地預覽
python3 -m http.server 8080
```

然後在瀏覽器中造訪 `http://localhost:8080` 即可開始學習！
